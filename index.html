About

I'm a Technical High School student in Electronics focused on hardware design and embedded electronics. My main interest sits at the intersection of microcontrollers, PCB layout, and automotive applications — how ECUs, sensor networks, and telemetry systems behave under real-world constraints.

Rather than just assembling circuits, I focus on analyzing their physical and logical behavior: analog signal conditioning, logic circuits, reading schematics, and debugging hardware with an oscilloscope and multimeter. ANALOG / PCB DESIGN

LED Chaser — Wearable

A fully analog wearable LED chaser, sized somewhere between an earring and a keychain clip. No microcontroller — a 555 astable oscillator clocks a CD4017 decade counter, sequencing 10 LEDs around the ring in a chase pattern.

Speed is adjustable via a potentiometer feeding the 555's timing network, and the whole board runs off a coin cell (BAT1) through a discrete supply. Designed end-to-end in EasyEDA — schematic capture, footprint placement, and two-layer routing on a compact circular board.

ANALOG / PCB DESIGN

Infrared Proximity Sensor

An infrared emitter/receiver pair (LED infrarrojo + phototransistor) feeds an op-amp comparator stage, which switches cleanly when an object enters range. A potentiometer sets the detection threshold on the comparator's reference input.

A low-pass filter (RL/C1) on the output smooths switching noise before the board drives a clean 5V pulse out — designed to be dropped straight into a digital input elsewhere in a larger system.

ANALOG / PCB DESIGN

Timed Output Driver

A trigger-in, timed-output driver board: a signal on the input (or a press on the onboard test button, KEY1) fires an NE555 monostable that holds a MOSFET-switched output active for a set duration — around 5 seconds by default, adjustable via the timing resistor.

Built around a BC547 input-conditioning stage feeding the 555, with an IRLR2905 MOSFET on the output stage for switching higher-current 12V loads from a 5V logic trigger.

RAND — Reconfigurable Articulated Node Driver

A wearable glove controller emulating a BLE HID mouse via gesture recognition, built on ESP32-C3 with a 4-state FSM (OFF, MOUSE_SCROLL, RECORDING, SERIAL). Includes a custom RAND Serial Protocol and a Python gesture-capture tool.

Debugged real hardware issues: BLE pairing instability, MPU6050 drift, irregular FreeRTOS task timing. Documented in full following ABNT (NBR 14724) technical report standards.
